Back to the editor

Write, add images, preview.

Choose Blog, Articles, Exploits, Research, or CVEs, then create an entry or edit an existing one.

Write your post

  1. Enter a title and short description.
  2. Leave Keep as draft on while writing.
  3. Use Heading 2 for major sections and Heading 3 for subsections. The page already provides your title as Heading 1.
  4. Add lists, links, quotes, and code blocks with the editor toolbar. Switch to raw mode to edit Markdown directly.

Add images

Use the cover image field for a header image. Use the image control inside the body for screenshots and diagrams. Upload JPG, PNG, or WebP files; keep files smaller than 10 MB for faster uploads. Add a useful image description for accessibility. Give uploads distinct names so you can identify them later.

Research publications

Choose Research for papers, patents, write-ups, and general research. Select the format and actual status, add authors or inventors, then the journal or patent office. You can add an abstract, DOI, patent number, original publication link, uploaded PDF, code link, and an exact citation or BibTeX entry.

CVE advisories

Use CVEs for actual vulnerability records. Add the identifier, product and versions, impact, mitigation, scoring source, timeline, and references. CVE record status and remediation status are separate. Leave unknown fields blank; new entries default to draft and Unscored.

Preview

The editor preview uses the website's fonts and write-up styles. The actual page adds reading time, a table of contents where supported, and site navigation. For the complete result, save and visit the local website in a second tab.

Save versus publish

In local mode, saving writes to the project on this computer. It does not update GitHub or the live website. Local preview includes drafts.

Once live publishing is connected, saves go to the GitHub repository and the hosting service rebuilds the site. Keep as draft must be off for a post to appear in a normal production build.

Start the local editor

From the project folder, run npm run editor, then visit localhost:1314/admin/. Keep the command running while editing. Stop it with Ctrl+C.
